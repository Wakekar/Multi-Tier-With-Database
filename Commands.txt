==>>   Installing AWS-CLI

sudo apt install unzip
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
aws --version


#######################################################################################################################################

Configure AWS - CLI


-  aws configure                  >> Enter Acces keys of AWS-User

######################################################################################################################################

Install Terraform

-  sudo snap install terraform --classic      
>>>   See Terraform Folder in the Repo 
>>>   Clone the Repo to access the Terraform file in Terminal 

- git clone https://github.com/Wakekar/Multi-Tier-With-Database.git
 
- git branch -a
- git checkout Aniket    >>   to change the branch

-  terraform init
-  terraform plan
-  terraform apply --auto-approve
